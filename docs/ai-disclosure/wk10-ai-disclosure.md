### 4. Prompt ที่ใช้ (ตัวอย่าง):

"ช่วยออกแบบ Wireframe ระดับ Mid-Fi สำหรับระบบ POS ร้านกาแฟ โดยมีหน้ารับออเดอร์ หน้าจัดการเมนู และหน้ารายงานยอดขาย ตาม Requirement และ User Story ที่กำหนด"

"ช่วยเขียนโค้ด HTML/CSS/JS สำหรับหน้ารับออเดอร์ หน้าจัดการเมนู และหน้ารายงานยอดขาย ตามรายละเอียดและรูปแบบที่กำหนด"

"ช่วยแก้ไข Bug ในโค้ด Frontend และตรวจสอบการทำงานของหน้าเว็บตามข้อกำหนด"

"ช่วยร่างรูปแบบใบเสร็จและ Sales Report แบบ Summary Report สำหรับระบบ POS ร้านกาแฟ"

### 5. ผลลัพธ์จาก AI:

AI ช่วยร่างโค้ด Frontend สำหรับหน้า POS หน้าจัดการเมนู และหน้ารายงานยอดขาย รวมถึงช่วยสร้าง Wireframe ระดับ Mid-Fi รูปภาพสินค้าจำลอง และช่วยร่างรูปแบบใบเสร็จ รายงานยอดขาย และ Sequence Diagram สำหรับรายงานยอดขาย

### 6. การปรับแต่งของนิสิตเอง:

สมาชิกในกลุ่มเป็นผู้กำหนด Requirement และรูปแบบการทำงานของระบบ จากนั้นตรวจสอบและปรับแก้ผลลัพธ์จาก AI ให้ตรงกับ Requirement, User Story, Acceptance Criteria และรูปแบบงานของกลุ่ม รวมถึงแก้ไขโค้ดและรายละเอียดของ Wireframe ก่อนนำไปใช้งานจริง

### 7. เหตุผลในการใช้ AI:

ใช้ AI เพื่อช่วยลดเวลาในการร่างโค้ด Frontend, Wireframe, รูปภาพประกอบ และเอกสารการออกแบบ รวมถึงช่วยค้นหาสาเหตุและแก้ไข Bug โดยสมาชิกในกลุ่มเป็นผู้ตรวจสอบความถูกต้องและทำความเข้าใจผลงานก่อนนำไปใช้จริง
