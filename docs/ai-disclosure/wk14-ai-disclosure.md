### 3. งานส่วนไหนใช้ AI:

- [ ] Requirement Analysis - ส่วน: -
- [ ] Database Design - ส่วน: -
- [ ] System Architecture - ส่วน: -
- [X] Document/Grammar Check - ส่วน: เรียบเรียงและจัดรูปแบบ `wk14-quality-review.md`
- [X] อื่นๆ:
  - ไล่ตรวจโค้ดจริงทุก endpoint (33 endpoint) เทียบ Code Review Checklist (ตรวจข้อมูลนำเข้า, IDOR, SQL Injection, การจัดการ error, race condition) และจัดระดับความเสี่ยง R1 ถึง R15
  - แก้โค้ด backend ใน `src/` (routes, controllers, models, middleware, `utils/password.js`) เช่น บังคับล็อกอินและตรวจบทบาท, hash รหัสผ่าน, transaction และตัดสต็อกแบบมีเงื่อนไข, ตรวจข้อมูลนำเข้า
  - แก้โค้ด frontend เฉพาะ JavaScript และ CSS สำหรับพิมพ์ (`public/js/report.js`, `order.js`, `menu.js`, `admin.js`, `public/order.html`) โดยไม่เปลี่ยนหน้าตาที่ผู้ใช้เห็น
  - รัน `npm audit fix` (แก้เฉพาะ `package-lock.json`)
  - เขียนสคริปต์ทดสอบชั่วคราวเรียก API จริงและทดสอบผ่านหน้าจอบนเบราว์เซอร์ (สคริปต์ไม่ได้เก็บใน repository) ผลทดสอบบันทึกใน `wk14-quality-review.md`
  - ร่างเอกสาร SRS ฉบับรวม `wk10-srs.md` จากเอกสารของกลุ่ม (wk03, wk04, wk07, wk10) และปรับตามผลทดสอบ

### 4. Prompt ที่ใช้ (ตัวอย่าง):

"ลองทดสอบให้แล้ว update ในwk14-quality-review.md ให้ตรงกัน"

### 5. ผลลัพธ์จาก AI:

AI สรุปความเสี่ยง 15 รายการ (เช่น endpoint 17 ตัวเรียกได้โดยไม่ล็อกอิน, สต็อกติดลบเมื่อสั่งพร้อมกัน, รหัสผ่านเก็บเป็นข้อความธรรมดา, หน้ารายงานแสดง 0) แก้โค้ดตามที่ตกลง และทดสอบซ้ำจนผ่านทุกชุด (API 81 รายการ, `npm audit` เหลือ 0 ช่องโหว่) พร้อมบันทึกก่อน/หลังแก้ใน `wk14-quality-review.md`

### 6. การปรับแต่งของนิสิตเอง:

- ทีมกำหนดเงื่อนไข "UI คงเดิม" และตัดสินใจไม่แก้ปัญหา usability ของปุ่มยืนยันรับเงิน QR และข้อความเมนูหมด (บันทึกเป็นแผนใน `wk03-requirements.md` FR-11 และ FR-12)
- ทีมตรวจรายงาน แล้วสั่งให้ AI แก้ข้อความที่ระบุเกินจริง เช่น ตัดรายการ "ปุ่มชำระเงินอยู่ล่างสุด" ที่เกิดจากหน้าต่างทดสอบเตี้ย และตัดแถว ER Diagram ที่ไม่ใช่ความเสี่ยงของโค้ดออกจากรายงาน


### 7. เหตุผลในการใช้ AI:

งานนี้ต้องตรวจโค้ดทุก endpoint ตาม checklist และแก้หลายไฟล์พร้อมทดสอบซ้ำ ใช้ AI ช่วยเพื่อไล่ตรวจให้ครบและเร็วขึ้น ส่วนการตัดสินใจว่าจะแก้หรือไม่แก้ประเด็นใด และการตรวจความถูกต้องของรายงาน เป็นของทีม
